# WSPORT

## Обзор проекта
- **Название**: WSPORT (бренд на экране входа обновлён с «ФОРМА» на «WSPORT»)
- **Цель**: фитнес-сайт с расчётом нормы КБЖУ, подбором рецептов и упражнениями для зала
- **Стек**: чистый HTML/CSS/vanilla JS SPA, статика на Cloudflare Pages (worker `47733657-aa80-42b6-861e-c5b1d3a78291`)

## Что сделано в этой сессии
1. **Экран входа**: название заменено на «WSPORT»; текст «Аккаунт хранится только в этом браузере…» заменён на короткое, аккуратное описание сайта.
2. **Расчёт КБЖУ**: `calcNorm()` в `app.js` использует формулу Миффлина-Сан Жеора (BMR) и рекомендации ISSN Position Stand по белку (1.6–2.2 г/кг) и жирам (мин. 0.6 г/кг) — с комментариями в коде, объясняющими научное обоснование.
3. **Анимация подсветки БЖУ**: `.macro`/`macropop` в `styles.css` смягчена — длительность увеличена с 0.42s до 1.1s, ослаблен scale, добавлен плавный box-shadow переход вместо резкого мигания.
4. **Фото рецептов**: все 48 рецептов (36 ранее без фото + 12 уже имевших) теперь содержат `img` в `data.js`, файлы лежат в `public/static/img/food/`.
5. **Кнопка «Другой вариант»** удалена — она дублировала функцию «Собрать день».
6. **Анимация в разделе рецептов**: добавлен shimmer-блик по фото карточки при наведении (`.rphoto::before` + `@keyframes rshine`) и лёгкое появление бейджа калорий (`@keyframes rtagpop`), чтобы раздел не выглядел пустым.
7. **Бренд WSPORT везде**: заменены остававшиеся упоминания «ФОРМА» — `<title>`, бренд онбординга, бренд в сайдбаре приложения, бренд в верхней панели (topbar).
8. **Toast-уведомления при входе/регистрации**: после успешного входа снизу экрана показывается «Успешный вход!», после успешной регистрации — «Успешная регистрация!» (использован уже существовавший в проекте компонент `#toast`, просто добавлены вызовы в нужных местах).
9. **Ручной ввод КБЖУ**: на вкладке «Норма КБЖУ» добавлен переключатель «Рассчитать по параметрам» / «Указать свои цифры». В режиме ручного ввода пользователь задаёт калории, белки и жиры сам (углеводы досчитываются автоматически по остатку калорий). Введённые значения проверяются и мягко корректируются:
   - калории ограничены диапазоном 800–6000 ккал;
   - белки — 20–400 г, жиры — 20–300 г;
   - если известен вес пользователя, белок дополнительно ограничен ~3 г/кг, жиры ~2 г/кг (ISSN-рекомендации);
   - если белки+жиры «съедают» больше 85% калорий, они пропорционально уменьшаются, чтобы осталось место для углеводов;
   - под полями выводится понятное объяснение, что и почему было скорректировано.
   Выбранный режим (авто/ручной) и введённые значения сохраняются в профиле пользователя (localStorage) при нажатии «Сохранить в профиль».
10. **Расширена база упражнений (зал)**: было 26, добавлено 19 новых — теперь **44 упражнения** во всех группах. Каждое новое упражнение содержит фото, целевые/вторичные мышцы (в т.ч. коды для анатомической SVG-схемы), рекомендованные подходы/повторы, шаги техники и частую ошибку — по той же схеме, что и старые записи. Разбивка по группам:
    - **Грудь** (4 → 8): + сведение в кроссовере, пек-дек, жим на скамье с наклоном вниз, отжимания с узкой постановкой рук (алмазные)
    - **Спина** (4 → 7): + тяга Т-штанги, шраги со штангой, классическая тяга штанги (дедлифт)
    - **Ноги** (6 → 9): + разгибание ног в тренажёре, болгарские выпады, подъём на носки сидя
    - **Плечи** (3 → 5): + тяга штанги к подбородку, сведение на заднюю дельту в тренажёре
    - **Руки** (4 → 7): + французский жим лёжа, подъём на бицепс на скамье Скотта, концентрированный подъём на бицепс
    - **Пресс** (3 → 5): + велосипед (скручивания с поворотом), ролик для пресса (ab wheel)
    - **Ягодицы** (1 → 3): + отведение ноги назад в кроссовере, мост на одной ноге

- **Хранение пользовательских данных**: localStorage браузера (без сервера)

## Как пользоваться
1. Зарегистрироваться/войти на экране входа (WSPORT) — после успешного действия внизу экрана появится уведомление.
2. На вкладке «Норма КБЖУ» выбрать способ: рассчитать по параметрам (пол, цель, возраст, рост, вес, активность) или указать свои цифры калорий/БЖУ вручную — сервис проверит их на адекватность и подскажет, если что-то нужно скорректировать.
3. На вкладке рецептов выбрать «Готовый день» → «Собрать день» — меню подберётся под цель.
4. Каждый рецепт имеет фото, время готовки, калории и БЖУ.
