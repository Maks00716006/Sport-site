# ФОРМА — питание и тренировки

## Обзор проекта
- **Название**: ФОРМА (FORM)
- **Цель**: Личный трекер питания и тренировок — расчёт нормы КБЖУ, база рецептов, конструктор дня, дневник веса и база упражнений с анатомическими подсказками мышц.
- **Особенность**: 100% клиентское приложение (vanilla JS, без фреймворков), все данные пользователя хранятся в `localStorage` браузера — никакого backend/сервера не требуется.

## Структура проекта
Сайт был разделён из единого файла `index.html` (1.44 МБ, где 92% занимали встроенные в base64 картинки) на отдельные файлы для лучшей поддерживаемости и кэширования браузером:

```
webapp/
├── public/
│   ├── index.html          # Разметка (14 КБ, было 1.44 МБ)
│   └── static/
│       ├── styles.css      # Все стили (было 2 инлайн <style> блока)
│       ├── data.js         # Данные: RECIPES, EXERCISES, GROUPS, MUSCLE_NAME
│       ├── app.js          # Вся логика приложения (авторизация, навигация,
│       │                     калькулятор КБЖУ, рецепты, конструктор дня,
│       │                     дневник веса с графиком, упражнения+анатомия, история)
│       └── img/
│           ├── hero.jpeg        # Картинка экрана авторизации
│           └── <exercise>.jpeg  # 25 фото техники упражнений (bench, squat, ...)
├── wrangler.jsonc           # Конфиг Cloudflare Pages (статический хостинг)
├── package.json
└── ecosystem.config.cjs     # PM2-конфиг для локальной разработки
```

**Важно**: `hero.jpeg` и `bench.jpeg` — побайтово идентичные файлы (совпадение из оригинального сайта: автор использовал фото жима штанги и для экрана авторизации, и для карточки упражнения "Жим штанги лёжа"). Это не ошибка экстракции, а особенность исходных данных.

## Функциональность
- **Норма КБЖУ**: расчёт по формуле Миффлина–Сан Жеора (пол, возраст, рост, вес, активность, цель → ккал/белки/жиры/углеводы, разбивка по приёмам пищи). Добавлена анимация: плавный счётчик ккал при пересчёте, анимированная пульс-линия в шапке карточки, плавное заполнение полосы БЖУ, «pop»-эффект на карточках макросов.
- **Рецепты**: 48 рецептов (36 базовых + 12 новых, у каждого нового есть фото готового блюда) с фильтрами по приёму пищи и способу приготовления, рейтинг звёздами. Карточки — с фото/иконкой, анимацией появления и hover-эффектом (подъём + масштаб фото).
  - Внутри вкладки «Рецепты» есть переключатель **«Все рецепты» / «Готовый день»** — отдельная вкладка «Готовый день» убрана из основной навигации и перенесена сюда же, чтобы весь функционал по еде был в одном месте. Конструктор дня автоматически подбирает порции под целевую калорийность.
- **Мой вес**: дневник веса с canvas-графиком динамики
- **Упражнения**: 25 упражнений с фото техники, анатомическими SVG-диаграммами тела (подсветка основных/вторичных мышц), инструкцией и частыми ошибками
- **История блюд**: журнал приготовленных рецептов с оценками

## Хранение данных
- `localStorage` ключ `forma-users-v2` — данные всех зарегистрированных пользователей (профиль, вес, история, оценки)
- `localStorage` ключ `forma-session-v2` — текущая сессия (email залогиненного пользователя)
- Никакой сервер/база данных не используется — все данные живут в браузере пользователя

## Локальная разработка
```bash
npm install
npm run dev          # wrangler pages dev public --port 3000
```

## Деплой
- **Платформа**: Cloudflare Pages (статический сайт, без Workers-функций)
- **Команда деплоя**: `npm run deploy`
- **Статус**: готов к деплою, ещё не задеплоен

## Гид пользователя
1. Открыть сайт → создать аккаунт (имя, почта/логин, пароль) или войти в существующий
2. Заполнить параметры (пол, возраст, рост, вес, активность, цель) → получить норму КБЖУ
3. Листать рецепты, фильтровать по приёму пищи, добавлять в историю с оценкой
4. На вкладке «Готовый день» — сгенерировать меню на день под свою норму
5. На вкладке «Мой вес» — вносить замеры и следить за графиком
6. На вкладке «Упражнения» — смотреть технику, задействованные мышцы (анатомические схемы), частые ошибки
